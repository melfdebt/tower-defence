# Tower Defense — Practice 3

## 1. Описание проекта

Проект представляет собой прототип игры на **Godot Engine 4 с использованием C#**. Игровое поле содержит башню игрока и вражескую башню. Объекты обнаруживают противников, перемещаются в их направлении и атакуют с помощью снарядов.

Архитектура построена на компонентном подходе: поведение игровых объектов разделено на отдельные компоненты, отвечающие за здоровье, движение, стрельбу и обнаружение целей.

## 2. Структура проекта

```text
practice-3/
├── components/
│   ├── HealthComponent.cs
│   ├── MoveComponent.cs
│   ├── ShootComponent.cs
│   └── VisibilityComponent.cs
├── scenes/
│   ├── Field.tscn
│   ├── tower.tscn
│   ├── enemy.tscn
│   ├── Bullet.tscn
│   ├── enemyBullet.tscn
│   └── Bullet.cs
├── project.godot
├── practice3.csproj
└── practice3.sln
```

- `components/` — скрипты компонентов, реализующих отдельные функции игровых объектов.
- `scenes/` — игровые сцены и скрипт с логикой снаряда.
- `project.godot` — настройки проекта Godot.
- `practice3.csproj` и `practice3.sln` — файлы проекта и решения C#.

## 3. Структура сцен

### Field.tscn — игровое поле

Главная сцена, объединяющая игровые объекты и окружение.

Содержит:
- `WorldEnvironment` — настройки окружения и освещения.
- `floor` — игровая площадка, включающая башни и элементы окружения.
- `Tower` — экземпляр сцены башни игрока.
- `enemy` — экземпляр сцены вражеской башни.
- `StaticBody3D` с `CollisionShape3D` — статическая поверхность с физической коллизией.
- `MeshInstance3D` — визуальное представление поверхности.
- `Camera3D` — игровая камера.
- `AreaLight3D` — источник освещения.

### tower.tscn — башня игрока

Корневой узел — `CharacterBody3D`.

Содержит:
- `MeshInstance3D` — визуальная модель башни.
- `CollisionShape3D` — форма физической коллизии.
- `HealthComponent` — управление здоровьем.
- `MoveComponent` — движение к выбранной цели.
- `ShootComponent` — поворот в сторону цели и стрельба.
- `VisibilityComponent` — обнаружение противников.

Башня игрока принадлежит группе `tower`.

### enemy.tscn — вражеская башня

Корневой узел — `CharacterBody3D`.

Структура аналогична башне игрока: визуальная модель, физическая коллизия и четыре компонента поведения.

Вражеская башня принадлежит группе `enemy`. Это позволяет отличать её от башни игрока при выборе целей.

### Bullet.tscn — снаряд игрока

Корневой узел — `Area3D`.

Содержит:
- `CollisionShape3D` — обнаружение столкновений.
- `MeshInstance3D` — визуальное представление снаряда.
- `Bullet.cs` — движение, обработку столкновений и нанесение урона.

### enemyBullet.tscn — снаряд противника

Отдельная сцена снаряда вражеской башни. Использует собственные настройки физической коллизии и визуального представления. Логика движения, попадания, нанесения урона и удаления реализуется скриптом `Bullet.cs`.

## 4. Назначение компонентов

### HealthComponent

**Управление здоровьем игрового объекта.**

Основные функции:
- Инициализация текущего здоровья значением `MaxHealth`.
- Уменьшение здоровья методом `TakeDamage()`.
- Удаление родительского объекта при достижении нулевого здоровья.

Основные параметры:
- `MaxHealth` — максимальное здоровье объекта.

### MoveComponent

**Управление движением объекта к цели.**

Компонент получает ссылку на родительский `CharacterBody3D` и перемещает его в направлении цели.

Основные функции:
- `SetTarget()` — установка цели.
- `Move()` — расчёт направления и скорости движения.
- `MoveAndSlide()` — перемещение с учётом физики Godot.

Основные параметры:
- `Speed` — скорость движения.
- `StopRadius` — расстояние, при котором объект прекращает приближаться к цели.

### ShootComponent

**Управление стрельбой.**

Компонент поворачивается в сторону выбранной цели и запускает таймер стрельбы. При срабатывании таймера создаётся экземпляр снаряда, которому задаются начальная позиция, направление, скорость и урон.

Основные функции:
- `SetTarget()` — установка цели.
- `TurnOnCannon()` — запуск стрельбы.
- `TurnOffCannon()` — остановка стрельбы.
- `SpawnBullet()` — создание снаряда.

Основные параметры:
- `BulletScene` — сцена используемого снаряда.
- `BulletDamage` — урон снаряда.
- `FireRate` — частота стрельбы.
- `BulletSpeed` — скорость снаряда.

### VisibilityComponent

**Обнаружение целей и передача информации другим компонентам.**

Наследуется от `Area3D` и использует `CollisionShape3D` для определения объектов, попадающих в область обнаружения.

Основные функции:
- Обработка сигналов `BodyEntered` и `BodyExited`.
- Проверка принадлежности объектов к группам.
- Добавление допустимых целей в список обнаруженных объектов.
- Выбор ближайшей цели.
- Передача цели в `ShootComponent` и `MoveComponent`.

Основные параметры:
- `shootComponent` — ссылка на компонент стрельбы.
- `moveComponent` — ссылка на компонент движения.

## 5. Взаимодействие компонентов

Основной цикл взаимодействия выглядит следующим образом:

1. `VisibilityComponent` обнаруживает объект в своей области видимости.
2. Проверяется наличие у объекта `HealthComponent` и допустимость его выбора в качестве цели.
3. Из обнаруженных объектов выбирается ближайший.
4. Цель передаётся в `MoveComponent` и `ShootComponent`.
5. `MoveComponent` перемещает башню к цели.
6. `ShootComponent` поворачивается к цели и создаёт снаряды через заданный интервал.
7. При столкновении снаряд обращается к `HealthComponent` цели и наносит урон.
8. При достижении нулевого здоровья объект удаляется из сцены.
